================================================================================
                         MiniOS - Run & Test Instructions
================================================================================

1. SYSTEM REQUIREMENTS
--------------------------------------------------------------------------------
- GCC Compiler (installed by default on macOS with Xcode CLI tools, or Linux build-essential)
- Make utility (optional, direct gcc command also provided)
- Supported Platforms: macOS, Linux, and Windows (MinGW / WSL / Cygwin)


2. COMPILATION INSTRUCTIONS
--------------------------------------------------------------------------------
Open a terminal in the project directory:
    cd /Users/aarushdubey/Downloads/os_project

Option A (Using Makefile - macOS / Linux):
    make clean
    make

Option B (Direct GCC compilation - macOS / Linux):
    gcc -Wall -Iinclude -o minios src/main.c src/process.c src/scheduler.c src/memory.c src/sync.c src/pager.c src/disk.c

Option C (Windows using MinGW):
    gcc -Wall -Iinclude -o minios.exe src/main.c src/process.c src/scheduler.c src/memory.c src/sync.c src/pager.c src/disk.c


3. HOW TO LAUNCH
--------------------------------------------------------------------------------
OPTION 1: Interactive Terminal Shell
On macOS / Linux:
    ./minios

On Windows:
    minios.exe

OPTION 2: Interactive Web UI Dashboard (Recommended for Visual Testing)
Run the built-in UI server:
    python3 ui/app.py

Then open your browser and navigate to:
    http://127.0.0.1:5050
(All modules can be triggered with one click: load sample jobs, compare
schedulers, allocate/free memory, run Banker's algorithm, and test page/disk)


4. STEP-BY-STEP TESTING GUIDE (INTERACTIVE SHELL)
--------------------------------------------------------------------------------

[A] Process Management & CPU Scheduling Test
--------------------------------------------------------------------------------
1. In the MiniOS shell, create 5 sample processes:
    create P1 7 3 0
    create P2 4 1 2
    create P3 1 4 4
    create P4 4 2 5
    create P5 3 5 6

    (Format: create <process_name> <burst_time> <priority> <arrival_time>)

2. View the current process table:
    list

3. Run individual CPU scheduling algorithms:
    schedule fcfs
    schedule sjf
    schedule rr 2
    schedule priority
    schedule mlfq

4. Compare all CPU scheduling algorithms in a summary table:
    schedule compare


[B] Memory Management Test (First Fit, Best Fit, Worst Fit)
--------------------------------------------------------------------------------
1. Allocate memory blocks to processes:
    mem_alloc P1 128 ff
    mem_alloc P2 256 bf
    mem_alloc P3 64 wf

    (Policies: ff = First Fit, bf = Best Fit, wf = Worst Fit)

2. View current memory allocation map:
    mem_status

3. Free a process block and inspect merging:
    mem_free P1
    mem_status

4. Reset memory arena to initial state:
    mem_reset


[C] Process Synchronization & Deadlock Avoidance Test
--------------------------------------------------------------------------------
1. Run Producer-Consumer simulation (shows buffer state & semaphores):
    producer_consumer

2. Run Banker's Algorithm:
    bankers

   Sample Input when prompted:
   - Number of processes: 5
   - Number of resource types: 3
   - Allocation Matrix:
       P0: 0 1 0
       P1: 2 0 0
       P2: 3 0 2
       P3: 2 1 1
       P4: 0 0 2
   - Max Matrix:
       P0: 7 5 3
       P1: 3 2 2
       P2: 9 0 2
       P3: 2 2 2
       P4: 4 3 3
   - Available Resources:
       3 3 2


[D] Virtual Memory & Page Replacement Test
--------------------------------------------------------------------------------
Run comparison of FIFO, LRU, and Optimal algorithms with 3 frames:
    page compare 3 7,0,1,2,0,3,0,4,2,3,0,3

Or run individually:
    page fifo 3 7,0,1,2,0,3,0,4,2,3,0,3
    page lru 3 7,0,1,2,0,3,0,4,2,3,0,3
    page optimal 3 7,0,1,2,0,3,0,4,2,3,0,3


[E] Disk Scheduling Test
--------------------------------------------------------------------------------
Compare FCFS, SSTF, SCAN, and C-SCAN from initial head position 53:
    disk compare 53 98,183,37,122,14,124,65,67

Or test individually:
    disk sstf 53 98,183,37,122,14,124,65,67
    disk scan 53 98,183,37,122,14,124,65,67
    disk cscan 53 98,183,37,122,14,124,65,67


[F] Exiting MiniOS
--------------------------------------------------------------------------------
Type:
    exit


5. QUICK ONE-LINE AUTOMATED DEMO TEST
--------------------------------------------------------------------------------
To verify all major features in 5 seconds without manual typing, run:

printf "create P1 7 3 0\ncreate P2 4 1 2\ncreate P3 1 4 4\ncreate P4 4 2 5\ncreate P5 3 5 6\nlist\nschedule compare\nmem_alloc P1 128 ff\nmem_alloc P2 256 bf\nmem_status\nmem_free P1\nmem_status\nproducer_consumer\npage compare 3 7,0,1,2,0,3,0,4,2,3,0,3\ndisk compare 53 98,183,37,122,14,124,65,67\nexit\n" | ./minios
